
🖥️ SysAdmin MCP Server
A powerful Model Context Protocol (MCP) server built with Python and FastMCP. This server allows AI agents (like Claude Desktop) to monitor and retrieve real-time system statistics directly from your local machine.

✨ Features
This server provides tools to monitor the following:

OS Info: Retrieve system name, kernel version, and architecture.

CPU Stats: Real-time load percentage, core count, and clock frequency.

Memory: Detailed RAM usage (Total, Used, Available) in GB.

Disk Usage: Check available space and health for any specific path or drive.

Uptime: Get the exact date and time of the last system boot.
